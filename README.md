# 深水网箱/浮动平台历史案例智能检索系统

> 业务人员销售时快速查找相似历史项目案例，提高谈客效率的智能检索系统。

## ✨ 功能特点

- **📚 项目案例库**：展示所有已录入的历史项目列表，支持按类型筛选和关键词搜索
- **🔍 智能检索**：输入新项目参数（海况、规格、类型等），智能匹配最相似的历史案例
- **📋 案例详情**：完整展示项目信息，包括海况参数、技术规格、方案图纸、材料统计等
- **📤 数据导入**：支持上传Excel项目信息表和图纸文件，自动解析入库
- **📱 响应式设计**：电脑、手机、平板都能流畅使用
- **🖼️ 图纸在线预览**：支持PDF和图片格式的图纸在线预览

## 🚀 快速启动

### 方式一：双击启动（推荐）

直接双击 `start.bat` 即可启动系统。

首次启动会自动安装依赖包（约1-2分钟），之后启动会很快。

### 方式二：命令行启动

```bash
# 安装依赖
pip install -r requirements.txt

# 启动应用
python app.py
```

### 访问地址

启动后在浏览器中打开：**http://127.0.0.1:5000**

## 🎯 使用指南

### 1. 浏览案例库

首页展示所有历史项目案例，可按项目类型（网箱/平台/防波堤）筛选，也可输入关键词搜索。

点击项目卡片进入详情页查看完整信息。

### 2. 智能检索

进入「智能检索」页面，填写新项目的参数：

- **项目类型**：网箱 / 平台 / 平台＋网箱 / 防波堤
- **海况参数**：水深、波高、流速、水位差、风速、底质类型等
- **技术规格**：管径、周长、网箱数量、平台面积等
- **关键词**：项目特点、用途等描述

点击「开始匹配」，系统会从多个维度计算相似度，返回最相似的历史案例，按相似度从高到低排序。

### 3. 查看案例详情

在案例详情页可以查看：

- 项目基本信息和概述
- 海况参数（水深、波高、流速、底质等）
- 网箱技术参数（管径、周长、网衣、锚点等）
- 平台技术参数（尺寸、承载力、附属设施等）
- 防波堤参数（减波率、规格等）
- 方案图纸（支持在线预览）
- 项目照片
- 材料统计表

### 4. 数据导入

进入「数据导入」页面：

**导入项目信息表：**
- 点击上传区域，选择 `.xls` 或 `.xlsx` 格式的项目信息表
- 系统自动解析项目名称、类型、海况参数、技术规格等字段
- 解析成功后自动创建项目记录

**上传图纸：**
- 先选择对应的项目
- 上传 PDF 或图片格式的方案图纸
- 图纸会关联到所选项目，支持在线预览

## 🧮 智能匹配算法说明

系统采用**多维度加权相似度算法**，综合以下因素进行匹配：

| 维度 | 权重 | 说明 |
|------|------|------|
| 项目类型 | 20% | 硬性筛选条件，类型不匹配得分很低 |
| 水深 | 15% | 数值接近度打分 |
| 最大波高 | 12% | 数值接近度打分 |
| 最大流速 | 10% | 数值接近度打分 |
| 管径 | 8% | 数值接近度打分 |
| 周长/直径 | 14% | 数值接近度打分 |
| 水位差 | 5% | 数值接近度打分 |
| 最大风速 | 5% | 数值接近度打分 |
| 底质类型 | 5% | 关键词匹配 |
| 网箱数量 | 5% | 数值接近度打分 |
| 平台面积 | 6% | 数值接近度打分 |
| 文本关键词 | 5% | 语义关键词匹配 |

数值相似度公式：`score = 1 / (1 + |v1 - v2| / avg)`，差值越小相似度越高。

## ❓ 常见问题

**Q: 启动时提示找不到Python？**
A: 请先安装 Python 3.8 或更高版本，下载地址：https://www.python.org/downloads/

**Q: 依赖安装很慢怎么办？**
A: 启动脚本已默认使用清华镜像源，如仍有问题可手动设置代理。

**Q: 如何重置数据？**
A: 删除 `data/case_search.db` 文件，重新启动即可重新导入样例数据。

**Q: 支持什么格式的Excel？**
A: 支持 `.xls` 和 `.xlsx` 格式，需使用系统标准的「项目信息表」模板格式。

**Q: 手机端怎么使用？**
A: 确保电脑和手机在同一局域网，手机浏览器访问电脑IP:5000即可使用。
